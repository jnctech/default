# Journal (optional)

A weekly log of what the prompt pack surfaced. Keep it or skip it — nothing else in the pack depends on this folder.

Suggested filename pattern: `YYYY-Www.md` (e.g. `2026-W21.md`) so files sort chronologically.

Suggested one-page template per week:

```
# Week of YYYY-MM-DD

## Inbox snapshot (Friday end-of-day)
- Inbox count: ___
- U: ___   AR: ___   CA: ___   (CA >14d that didn't archive: ___)

## P3 reconciliation highlights
- PROMOTE-CA: ___ items
- KEEP-with-followup: ___ items
- Sources cited most: ___, ___, ___

## P5 findings
- Missed AR/U candidates: ___
- Allow-list adds: …
- Deny-list adds: …
- Registry adds: …

## Notes / drift
- (anything that felt off this week)
```

If counts drift upward week over week, run P5 mid-week instead of waiting for Friday.
