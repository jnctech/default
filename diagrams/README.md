## What's locked vs what's free (image-gen prompts)

**Locked across every prompt** — model must not change:
- Hierarchy and tier order
- Every text label, IP, port number, CIDR (rendered verbatim)
- Which nodes connect to which
- Visual cue that IoT VLAN 70 is **PLANNED, not deployed**
- Visual cue that the three security cards are **warnings**

**Free in the loose prompt** — model decides:
- Aesthetic direction
- Colour palette
- Typography
- Glyph language for each node type
- Line weighting and dashing
- Depth, shadow, gradients
- Density and breathing room

The three variant prompts commit to a specific aesthetic direction but
leave palette / typography / glyph micro-choices to the model.

## Topology — what the diagram describes

Top-to-bottom tiers:

1. **Internet (WAN)**
2. **Two remote-access paths:** Cloudflare Tunnel (HTTPS 443 → cloudflared) and **WireGuard** (UDP/13231 → RB4011, peer `samsung-phone .100.2`, bypasses CF)
3. **Cloudflare Tunnel** at `colebungalow.com`
4. **External Domain Map** — 10 subdomains with auth method (Direct / OIDC / Forward-Auth)
5. **Infrastructure Network · 192.168.30.0/24:**
   - **NPM** (`.30.28` · CT 118 + cloudflared)
   - **Docker Host** (`.30.10` · docker-vm01 · VM 102): Authentik · Gitea · Gitea Runner *prominent*; also Grafana, Loki, Promtail, Pi-hole primary, Unbound, FamilyLink Auth, Obsidian LiveSync, Portainer Agent, Dev Container, Homework
   - **Asustor NAS** (`.30.22`): Portainer, Sonarr, Radarr, SABnzbd, Tautulli, Overseerr
   - **Additional LXCs:** Vaultwarden (CT 117 · `.30.29`), Gotify (CT 116 · `.30.26`)
6. **Inter-network routing** with firewall model callout: `trust_lan_interface_list` (no per-flow VLAN gates)
7. **Home Network · 192.168.88.0/24:** Home Assistant (`.88.43` · VM 111), Pi-hole secondary (`.88.35` · RPi), Zigbee Coord (`.88.50` · slzb-06m), Proxmox PVE (`.88.10`)
8. **IoT · VLAN 70 · ⚠ PLANNED, NOT DEPLOYED** — configs exist in `apps/mikrotik/` but not applied on RB4011 (ISS-260517-vlan-70-fate)
9. **VLAN inventory** — 8 VLANs: `default/88`, 20 (Users), 30 (Infra), 40 (Servers-2), 50 (DMZ), 60 (Guest), 70 (IoT, planned), 99 (Mgmt, leftover)
10. **MikroTik equipment:** RB4011 (gateway), CRS310 (switch), hAP ax3 (front), hAP ac2 (back)
11. **Security Open Issues:** Docker API `:2375` exposed unauthenticated · RouterOS API `:8728` plaintext · CRS310 SSH broken from VLAN 30

## Caveats

- **Physical port mapping was not in scope.** Only the three uplinks from the equipment tree were available (`sfp-sfpplus1` RB4011→CRS310; `ether10` RB4011→ax3; `ether1 PoE` ax3→ac2). CRS310 downstream ports, NAS port layout, Docker host NIC layout, PVE bridges, per-port VLAN tagging are all unknown.
- **Subdomain table is incomplete by design.** The system doc itself flags *"NETWORK-INFRASTRUCTURE.md subdomain table only has 10 of ~20 subdomains"* — diagram shows the canonical 10.
- **Ports left off some nodes** (no port given in yaml): Vaultwarden, Gotify, Proxmox PVE web UI (`:8006` is standard but not stated), FamilyLink Auth, Unbound (internal-only), Obsidian LiveSync. NPM admin UI `:81` was mentioned in the doc but not surfaced on the NPM chip.
- **Image-gen prompts were not run.** This bundle does not contain a generated poster — the Mermaid render is the only in-session visual. To get an actual stylistic poster, paste one of the `*.prompt.md` files into an image model (Gemini Imagen is recommended for text rendering).

## Verify after generation

When you do run a prompt through an image model, sanity-check the output against `homelab-network-extended.svg`:

1. Are all 10 subdomains in the domain map present and unswapped?
2. Are all service port numbers correct (not hallucinated)?
3. Is VLAN 70 visibly *not* deployed?
4. Are the three security cards visibly warnings?
5. Are all 14 tiers present in order, none dropped?

Image-gen models routinely garble text. The SVG is authoritative; the
generated image is a stylistic companion, not a replacement.
